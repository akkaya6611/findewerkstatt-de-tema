# OTOTAMİR-360 Modern Directory Teması

Türkiye geneli 81 ilde oto tamircileri, özel yetkili servisleri ve yol yardım ustalarını listeleyen modern, hızlı ve SEO optimize WordPress rehber teması.

## Özellikler
- 81 İl ve İlçe bazlı gelişmiş filtreleme ve usta arama motoru
- 13 Uzmanlık kategorisi & araç markası taksonomileri
- SEO dostu breadcrumbs, JSON-LD Schema (LocalBusiness & AutoRepair)
- İnteraktif SVG Türkiye Haritası
- Canlı istatistik sayaçları ve modern glassmorphism kart tasarımları
- Usta detayında Google Haritalar yol tarifi entegrasyonu, WhatsApp & Hemen Ara butonları
- GitHub üzerinden WordPress paneli içi otomatik tema güncelleme (PUC Entegrasyonu)
